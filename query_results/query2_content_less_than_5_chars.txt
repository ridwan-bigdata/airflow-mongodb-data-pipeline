QUERY 2: All Entries Where Content Length Is Less Than 5 Characters
MongoDB Query:

db.reviews.aggregate([
  {
    $match: {
      $expr: {
        $lt: [
          {
            $strLenCP: {
              $toString: "$content"
            }
          },
          5
        ]
      }
    }
  },
  {
    $project: {
      _id: 0,
      content: 1,
      score: 1,
      at: 1
    }
  }
])
